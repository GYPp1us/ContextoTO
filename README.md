# ContextoTO

面向中文母语者的安卓篇章英语阅读应用。预置 48 篇考研英语一风格文章，以及 3,000 主背词、4,801 考纲词与 319 零语料词。短按词查看本句义项，长按词查看所在句的整句释义与从句结构；文章目录与查询层均覆盖整页磨砂。

## 学习系统

空间布局为 `[文章目录｜文章｜生词｜生词菜单]`，相邻互滑。生词页有复习、列表、词库三种模式：复习题只显示单词，从已有释义随机取一个答案；列表点按看详情，长按记住 / 忘记 / 归档。答案提交后立即反馈，0.5 秒后弹出共享详情，显示考点来源及具体查询出现。纠错只写独立 `question_issue` 表并撤销对应评分，不自动修正题库，也不上传。

支持系统文件选择器导入 TXT / Markdown 文章、UTF-8 CSV / TSV 词库、ZIP 批量包；先预览，再事务提交。词库列为 `word,translation`，可选 `pos,ipa_uk,ipa_us,rank,frequency`；示例位于 `tools/fixtures/`。导入无需联网，不自动把整库加入复习。每库可随机加入新词（默认 10 个，设置可改为 1–500），按钮有延迟反馈和防重复点击；统计主动已查询与长期间隔已学会比例，热度展示查询、书签推进及复习活动。

调度使用本地版本化指数遗忘曲线（不是 FSRS）。未复习词严格优先于任何已复习词，同一轮去重；到期词结合难度、查询出现与词频排序。取消原来的每日 10 个新词限制，新增每日不同复习词数量设置（默认 0，即不限，上限 2000）。后台异步准备下一题，题库索引复用；需要等待时显示本地准备阶段，不调用模型。答题详情可点空白关闭，长按重新自评只修改原评分，不增加评分或热度。句子与单词模块均跨提供商复用，旧缓存按需恢复而非清除。新查询保存精确词位；旧版只能证明词元查询的记录明确标为历史查询。沉浸顶栏以两行边缘布局自然避开挖孔，安全高度默认旧值的 70%，可调 30%–150%。

四面板跟随手指位移、限位并按速度吸附，可在归位过程中重新拖动。目录和生词菜单外露的主页面点击收起，整个屏幕均支持横向手势；选新内容使用 10% 缩放的 400ms 卡牌交换。设置位于阅读页左侧、目录下层，保存 / 返回平移回阅读。展开项收起时，下方立即补位；仅当新页面底部不足以维持当前视口时，保留最小页尾余量并由上滑回收，不允许向下扩张。所有磨砂叠加 20% 同背景色滤光；顶栏和固定保存栏重绘模糊后的正文，遮挡文字不可点击。目录固定磨砂顶 / 底栏，箭头入口按压只改字体颜色。引导前两步居中、可实际操作，空白不退出整个引导，系统返回全程屏蔽；演示不联网、不改学习记录。详见 [RC6 约定](docs/RC6_REQUIREMENTS.md)；历史验收见 [rc5 记录](docs/INTERACTION_ITERATION.md)。

当前发布：[v1.0.0-rc6](https://github.com/GYPp1us/ContextoTO/releases/tag/v1.0.0-rc6)，更新内容见 [rc6 说明](docs/releases/v1.0.0-rc6.md)。历史版本说明保留，不倒改旧验收记录。

## 开发

需要 JDK 17+、Android SDK API 36、Android SDK Build Tools 36、Python 3.10+。构建使用 Gradle Wrapper：

```powershell
python tools/import_content.py
.\gradlew.bat testDebugUnitTest assembleDebug
```

`tools/import_content.py` 从仓库中的两个原始压缩包生成 `app/src/main/assets/articles.json` 和 `lexicon.json`。生成过程检查 48 篇、323 段、三份词表行数；APK 只打包阅读所需的正文和词表，不打包源压缩包与审校材料。

本地磁盘空间紧张时可把缓存与构建结果放到另一磁盘：

```powershell
$env:GRADLE_USER_HOME='E:\ContextoTO-build\gradle'
$env:CONTEXTOTO_BUILD_ROOT='E:\ContextoTO-build\output'
.\gradlew.bat assembleDebug
```

模拟器参考比例为 1080×2376、440 dpi，与参考图的 1440×3168 等比。可通过参数调整模拟器尺寸与密度，`-Reset` 恢复默认值；脚本只接受 `emulator-*` 设备：

```powershell
.\tools\set_emulator_scale.ps1 -Width 1080 -Height 2376 -Density 440
```

应用内「接口与外观设置」的「正文比例」可分别调整字号（16–28 sp）、行距（125%–200%）、左右边距（12–44 dp）、段落间距（12–72 dp）与挖孔预留高度；「恢复参考图比例」可一键恢复阅读组合。句子浮层从顶部安全留白后开始排版，英文原句随字号按 1.12 倍显示。非沉浸模式在系统状态栏下留出约 0.8 行正文；沉浸模式使用可调的紧凑磨砂顶栏。正文标题采用 small caps，完整显示且支持短按单词和长按句子分析；目录标题最多显示两行。设置页全屏平移、底部固定磨砂保存栏，可检查 GitHub 最新版本（含预发布版）并在应用内下载，下载进度以浮层展示；取消、网络失败或应用进入后台会删除未完成文件，校验成功后交给系统安装器。「已查询单词加粗」与「静默推理」开关均默认关闭；前者不影响查询记录或缓存，后者关闭时不会发起后台模型请求。右上角百分比显示当前文章的句子缓存进度，点击仍可查看已有缓存。

「碎片专注」可选填 408 Dashboard 的 HTTPS 上报链接。应用读取 `/catalog` 后展示科目、事项及其真实数字 ID；仅当阅读页在前台时，以固定来源 `contextoto` 每 20 秒向 `/frame` 发送一次 focus，离开阅读页立即发送 idle。409 冲突或当日结算时停止上报；未配置链接时不会访问该服务。含访问令牌的链接由 Android Keystore 加密保存在本机，不预置于 APK 或仓库。

「沉浸状态栏」默认关闭。开启后隐藏系统状态栏，自绘篇名、时间、百分比和专注上报状态，保留摄像头挖孔安全区；从顶部滑动可临时唤回系统栏。不启用沉浸模式时，阅读页也会显示专注状态。「跟随书签」默认开启，以透明圆角背景沿当前句子的每行轮廓包裹，首尾行的缺角平滑变形；滚过该句或查询更后面的句子时向前推进，回看旧句不回退。旧段落书签无损迁移到该段首句，按文章持久化，点击顶部书签入口可返回；关闭开关只隐藏背景。标题过渡逐字保留 small caps 的字形、字号与颜色，不把整词当作统一字号重绘。「已查询单词加粗」默认关闭，开启后只改变字重，保留正文、标题及句子浮层的从句颜色。

## 模型设置与数据

应用默认使用 DeepSeek 官方 OpenAI Chat Completions 接口：`https://api.deepseek.com`、`deepseek-flash`。设置页按阅读、学习、连接、版本分类，用衬线标题分区；开关整行可点击，正文比例、模型与连接、碎片专注可折叠，并逐项下弹展开。每个提供商独立保存模型 ID 与 Chat Completions / Responses 协议，支持自定义 HTTPS 端点；首次使用在应用内输入自己的密钥，密钥经 Android Keystore 加密后保存在设备上，不加入仓库或 APK。模型服务不可用时，文章和预置词典仍可离线阅读。

两种协议共用标准 `GET /v1/models` 模型目录，可刷新、搜索、点选模型，也可手动填写 ID。端点可填写域名根地址、已有 `/v1` 路径或完整 `/chat/completions` / `/responses` 地址；带前缀的兼容网关保留其路径。目录按端点及凭据缓存，不发起推理。协议定义参照 [OpenAI 模型目录](https://developers.openai.com/api/reference/resources/models/methods/list)、[Responses 流式事件](https://developers.openai.com/api/reference/resources/responses/streaming-events)与 [DeepSeek 模型目录](https://api-docs.deepseek.com/api/list-models/)。解析仅使用 OFF / MAX：原型、音标、通用义项、本句义关闭思考；派生词、整句翻译、从句结构使用 MAX。目录明确不支持时提示更换模型，不暗中降档或开启思考。CC Chat 的 OFF 使用 `off`，Responses 使用 `none`；DeepSeek 官方另使用 `thinking.type=disabled`。接口返回可观察的推理内容或正数推理 token 时，OFF 模块拒绝落库。

英文正文当前随 APK 提供 [Tinos](https://github.com/googlefonts/tinos)，这是与 Times New Roman 版心尺寸兼容的开源衬线字体；许可见 `licenses/TINOS-OFL.txt`。如需在公开 APK 中使用原版 Times New Roman，须另取得可再分发的字体授权。

RC6 的模块是独立网络请求，不是大模板选字段：音标仅发送实际拼写、缺哪套口音只返回哪套；通用义项与派生词只发送已确认原型；本句义只发送原句、词形和位置；翻译和结构各自只发送一个句子。音标、本句义、必要的原型判定并行，确认原型后义项和派生词并行；全局最多 4 个请求。模块分别验证、立即事务合并与刷新，成功项不因其他项失败而丢失，重试只补失败项。歧义词元按具体出现判断，任何变形词查询均展示原型；不把原型发音当成实际词形发音。

所有单词和句子缓存独立于提供商、模型和协议。旧记录原样保留、按需恢复；新增模块不统一清空或重查。通用义项 / 派生词按正确词元共享，音标按实际拼写共享，本句义按原句和词位共享。关闭浮层只撤观察者；进度汇总各模块，100% 仅在验证和落库后显示。失败或截断的结果不冒充缓存。

另预置 ECDICT 通用高频 10,000 独立词元，附字典英式音标和词形索引；原考纲库保持独立。自定义词库可搜索预览、重命名、合并、导出 CSV、确认删除；删除仅移除来源，保留已入库词的释义快照和学习数据。本版不做单词条编辑。来源、源文件 SHA-256 和筛选规则见 [预置数据说明](docs/PRESET_DATA.md)，许可见 `licenses/ECDICT-MIT.txt`。

N01 / N02 的标题与正文预置 120 句和 2,582 个词位解析，可离线使用，不计主动查询或学习热度。设置中的 DATA 可用带版本及 SHA-256 的 ZIP 导出当前 / 全部文章与解析，或预览后补缺导入；不含复习、评分、纠错、热度、书签、阅读位置、查询历史、密钥或配置。导入先验证内容和区间，再单事务合并，已有有效本机解析优先。新预置也使用同一补缺机制，标记成功安装版本，覆盖安装不覆盖用户结果。

句子分析按原文内容和结构版本哈希缓存，不包含服务、模型或协议。启用静默推理后，当前文章的句子会逐句串行分析，命中缓存不重复请求；出错后停止，可手动重试。关闭浮层、切换文章、旋转、暂时离开应用或关闭静默推理，仅取消界面观察或后续排队，不取消已经发出的模型调用；同一进程内请求会继续校验、落库，重复查询复用在途任务。应用进程被系统终止或强制停止时无法保证请求继续执行。右上角有手动查询时显示其估算阶段百分比，否则显示当前文章的句子缓存比例；点击可查看后台任务与已缓存内容。阶段进度不是服务端提供的真实总 token 百分比，100% 仅在缓存写入后显示。后台调用仍消耗所选服务额度。静默缓存不计作主动查询；从句区间会与原文逐字校验，不匹配时不着色。

额外验证命令：`./gradlew testDebugUnitTest assembleDebugAndroidTest`；单测覆盖 HTTPS 模型目录鉴权、端点归一化、Chat / Responses 流式与普通 JSON 回复、字形样式和书签轮廓插值。连接模拟器后可运行 `./gradlew connectedDebugAndroidTest`，覆盖旧 SQLite 升级、跨提供商缓存复用、模块合并、补缺请求和查询离开后的落库。设备测试使用模拟响应，不发送付费请求。视觉夹具需要显式参数启用，仅存在于测试 APK，不随发布 APK 分发。

## 发布

`v*` 标签触发 GitHub Actions 构建与发布 APK。签名材料通过仓库 Actions Secrets 提供，构建日志和产物均不包含 API Key。签名密钥的持续保管很重要：后续版本必须使用同一密钥才能覆盖安装。
