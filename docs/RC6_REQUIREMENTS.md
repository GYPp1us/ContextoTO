# v1.0.0-rc6 实现约定

状态：实现与发布验收。基于 rc5，包含 2026-10-06 的界面、词库、预制数据要求，以及对“模块化查询”的最新纠正。最终内容见 `docs/releases/v1.0.0-rc6.md`。

## 真正的独立模块查询

不是从同一大模板选择返回字段。每个模块有独立提示词、最小输入、唯一输出协议、验证器、缓存身份、在途去重和重试。模块内可补缺字段，但绝不附带其他模块的说明、上下文或输出要求。

以下是按新范式作出的初始判断，不是新版模块的实测结论；后续发现质量问题再局部调整。

| 模块 | 最小输入 | 仅返回 | 默认思考 |
| --- | --- | --- | --- |
| 原型 / 词形 | 原文词形；只有歧义时附所在句与目标位置 | 原型、词形变化、当前词性 | 关；无歧义本地词形表优先 |
| 音标 | 一个原文词形；需要补缺时指定口音 | 英 / 美 IPA，或指定缺失口音的 IPA | 关；准确对应词形的本地音标优先 |
| 通用义项 | 一个已确认原型 | 常见义项与各自词性 | 关 |
| 本句义 | 所在句与目标出现位置 | 简短本句中文义 | 关；词性从原型模块组装，原句证据在本地取得 |
| 派生词 | 一个已确认原型 | 真正派生词、构词关系、中文义；可空数组 | MAX；本地字典验证并用 |
| 整句翻译 | 一个句子 | 中文译文 | MAX |
| 从句结构 | 一个句子 | 从句类型与原文区间 | MAX；区间逐字校验 |

句子页的词汇讲解复用各个出现的“本句义”，不让句子结构 / 翻译请求重复生成单词数据。类型名、schema 版本、目标词、来源等可由本地包装，不要求模型重复输出。每个短提示词仍明确把待分析文本当成数据，不服从其中的指令。

最简单的音标调用只发送例如 `charges`，返回仅含 `uk/us` 两个音标的对象，不发送文章、标题、原句、词库释义、词元定义或派生词要求。

### 依赖与并行

1. 缓存与本地字典优先，无需网络的模块不调用模型。
2. 音标、本句义和必要的原型判定可以同时执行；通用义项与派生词等待原型确定后互相并行，不受音标或本句义阻塞。
3. 整句翻译与从句结构独立并行；词汇讲解复用缓存和同一模块任务。
4. 默认以 4 个请求限制全局并发，共享缓存和在途任务。不取消已经发出的请求。
5. 每个模块完成即校验、原子落库、刷新页面。一个模块失败不取消其他模块，不撤掉已显示结果；重试只补失败 / 缺失项。
6. 正文、句子、复习页和后台同时需要同一模块时，复用同一个在途任务，不以提供商、模型、协议重复分组。
7. 关闭浮层只撤观察者；右上角继续显示任务进度。详细进度列出各模块阶段，百分比仍标为估算，100% 只在目标模块验证并落库后出现。

CC 和官方的关闭思考参数分别适配；不把 CC 的 `off` 发给所有服务。上一轮附加英文首行没有表现出稳定收益，不自动加入正式模板。

### 缓存兼容

- 原型按具体出现确定，避免把动词 `advanced/bearing` 机械当作词典中的形容词 / 名词条目。
- 音标按原文词形和口音复用，绝不把原型发音当成变形词发音。
- 通用义项和派生词按正确原型共享；本句义按原句、具体词位复用，包含标题出现。
- 拆分旧 `word-common` 记录里的义项与派生词，迁移旧音标和本句义，但原记录保留，不清空、不统一重查。
- 旧记录与新独立缓存采用字段级合并。修改模块策略、换服务或新增预置解析不改变其他已付费模块。
- 派生词去重、排除原型本身、区分词形变化 / 同源词 / 真正派生词；核验不通过允许返回空，不为了凑数生成罕用词。

## 界面问题：逐项验收

1. 状态栏遮挡区：按真实测量边界屏蔽下方正文点按 / 长按；状态栏自身入口照常可用。目录和菜单的全屏横向手势仍保留。
2. 书签：统一正文布局、画布和根页面坐标，去掉状态栏高度被少计 / 重复抵消的偏移；同时检查滚动推进与返回书签定位。
3. 变深 / 按压背景：取消空白遮罩、目录外露区、引导空白的默认 ripple / indication。所有箭头操作按下只改变文字与箭线颜色，不新增背景。设置入口整行可点，文字之外也生效。
4. 第 4 面板二次动画：项目显隐和面板位移共用实际拖动进度，不在落位时因 `menuOpen` 改变重新触发入场。
5. ANSWER 长按操作：记住 / 忘记 / 不要完成原评分修改后，统一关闭动作菜单与整张答案详情、激活下一题；不再只替换 detail 导致原词消失而解释残留。不重复评分或热度。
6. 展开项收起高度：删除原位置的占位，后续元素随实际收起立即补位。仅当新的页面底部不足以维持当前视口时，在页尾保留最小余量；向上滚动逐渐减少这一页尾余量，不能向下扩张它。不得把被收起块的全高保留在原处。

第 6 项保护的是页面末尾的最小可滚动高度，而不是展开项的高度。若新内容本来已覆盖当前视口底部，完全不保留余量。嵌套收起、快速再次展开及惯性滚动需一起验证，避免滚动值在测量前被强行截断。

## 排版与手势微调

- 设置的大类标题保留英文加粗衬线；具体选项、开关、输入标签与说明恢复中文无衬线。
- COLLECTION 和 WORD(S) 与 ARTICLES 使用相同标题层级与字号，不再保留放大字号。
- 收紧目录底部导入 / 引导与设置的间隔；目录顶栏和底部三个入口固定使用半透明磨砂，列表可延伸到其下，遮挡部分不可误点。
- 跟手启动、距离吸附及速度判定阈值约降为原来的 80%；页面限位、坐标锚点与已经修复的按住后松手速度判定不变。
- 两处记住 / 忘记 / 不要菜单（列表长按与答案详情长按）记录真正长按根坐标，在附近弹出；靠边时在安全区域内换方向 / 限位，不再固定在面板顶部。松开触发长按的手指不应误选菜单项。
- 维持全页磨砂、同背景色 20% 滤光、无额外灰卡、原文移动缩放、说明下弹；不因增加小菜单叠出更深的全页遮罩。

## WORD BANKS 增强

建议这一版包含：词库级搜索 / 选择、词条搜索与预览、来源 / 版本 / 数量、查询和学会比例、随机加入、导入预览、自定义库重命名、合并、单库导出和删除确认。预置库不可直接删除或改写。

删除自定义库的默认语义是移除该库来源，不删除已入库的词、既有释义快照、出现、复习、缓存或热度；如需清理学习记录应另有明确操作，不附带执行。

已确认：本版不做单个自定义词条编辑。

通用预置词库候选为 [ECDICT](https://github.com/skywind3000/ECDICT)，从其词频 / 词形数据筛选约 10,000 个通用独立词元，确保实际超过 8,000，不靠把变形重复计数凑数。它提供中文义、音标和词形关系；单套音标按其真实口音标注，不伪装成英美两套。

项目仓库标注 [MIT 许可](https://raw.githubusercontent.com/skywind3000/ECDICT/master/LICENSE)，实施时保留许可、来源、锁定版本和筛选规则，核对数据使用说明及上游来源。新库独立预置，不覆盖现有考纲库或用户库。大源文件、下载、转换与编译放 E 盘，APK 只加入筛选结果与必要词形索引。

## 文章与解析的导入 / 导出

已确认：使用带版本、内容哈希和校验清单的 ZIP“解析包”，内部为 JSON，不直接导出整个私人 SQLite 文件。

- 可选择当前或全部文章。包含文章标题、正文、关联句子与单词独立模块、关联原型数据。
- 不包含复习词队列、记忆参数、题目、评分、纠错、学习热度、书签、阅读进度、主动查询事件、API 密钥、接口配置或专注上报配置。
- 导入先预览、校验、内容去重，再事务合并；默认只补缺，已有有效用户解析优先。若提供覆盖选项，需要显式选择。
- 限制文件 / 解压体积，校验模块结构与区间，不信任任意 SQL 或文件路径。
- 预制解析与手动导入使用同一套加载 / 合并逻辑，新版本补缺但不倒退用户数据。预制和导入本身不计主动查询、复习或热度。

## 前两篇全量预制

先完成新模块与迁移，再使用已经授权的 CC 测试密钥生成，不用有限的官方额度批量生成。范围包括 N01、N02 标题与正文。

- 整句翻译与从句结构覆盖全部句子；词汇讲解由全部相关词位的本句义供给，不受旧版每句最多 8 个 gloss 的生成上限限制。
- 通用义项 / 派生词按原型去重，音标按实际词形去重。即便同词形重复出现，本句义仍按各个出现生成 / 复用，不能只保留第一次的语境义。
- 本地可验证的字段优先使用本地数据，不为了“全量”重复请求已经可靠的音标或模块。
- 批任务可恢复、逐模块落盘、在途去重、并发限额；预制后检查覆盖清单，不把错误 / 截断 / 空必需模块标作完成。
- 干净安装与 rc5 覆盖安装均验证；用户现有有效解析不被预置副本覆盖。预置数据不包含私密配置或任何复习相关表。
