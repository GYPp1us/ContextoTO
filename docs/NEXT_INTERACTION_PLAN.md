# 阅读与生词系统：交互 / 数据流草案

日期：2026-10-05。状态：方案已批准，实施版本为 1.0.0-rc4。导入采用 TXT / Markdown、CSV / TSV 与 ZIP。本文保留最初设计建议；实际交付差异见版本说明。

本案基于 1.0.0-rc3 的实际实现。与早期 PRODUCT_PLAN.md 冲突时，以本轮确认后的方案为准。文中的推荐值均为产品默认值草案，不是已经实现的功能。

## 1. 已确认与待确认

已确认：

- 空间顺序固定为 `[文章目录｜文章｜生词｜生词菜单]`，相邻互滑；两主页面平级，目录 / 菜单高一层，错位展开。
- 题面只显示单词；从该词已有的本句义、词库义、模型通用义中随机取一个答案，详情中说明选中的释义与来源。
- 列表点词打开详情，长按词弹出“记住了 / 忘记了 / 不要了”；阅读页原有短按词、长按句子保持不变。
- 题目错误只写独立纠错表，当前版本在主学习数据中撤销该次评分。不实现依据报告自动屏蔽、修正或重出题等处理逻辑。

已确认导入范围：TXT / Markdown 文章、CSV / TSV 词库及 ZIP 批量包。不包含 PDF / DOCX / XLSX / tar.gz。

下面按上述确认项细化。格式解析器与通用导入流程分离，未确认格式不先写进第一版范围。

## 2. 四页面与手势

两个同级主页面：阅读、生词。两个各自所属的侧菜单：文章目录、生词菜单。生词页面内再切换复习、列表、词库三个模式，不增加主页面层级。

空间顺序优先于“左 / 右页面”的口头叫法。手指向左滑进入空间上右侧的相邻页面，向右滑进入左侧相邻页面：

- 阅读左滑：进入生词，首次默认复习模式；生词右滑：回到原阅读位置。
- 生词继续左滑：展开右侧生词菜单；菜单里可选择复习、列表、词库，以及导入入口。
- 阅读右滑：展开左侧文章目录；目录中选文章后回阅读。
- 两个菜单均延用 80% 宽度、所属主页面让位 60% 的错层。文章目录从左侧出现，正文向右让位；生词菜单从右侧出现，生词页向左让位。反向滑或点外露主页面收起菜单。
- 阅读和生词互切是同层页面平移，不加磨砂。只有菜单、详情、进度、引导等覆盖层需要全页磨砂。
- 纵向滚动与横向切页按方向锁定，不能因斜向阅读滚动误开菜单。显示浮层时暂停底层切页手势。
- 系统返回先退二级菜单，再退详情、侧菜单；生词主页面返回阅读。阅读页面保留原有退出行为。

文章、阅读位置、书签、列表滚动和当前题目分别保存。首次启动仍恢复上次阅读的文章，不因生词模块加入而改掉原启动路径。切到生词时恢复未完成的题，而不是随机重出一题。

## 3. 沉浸式顶栏

不再把整个挖孔高度加成一条空白。第一行的内容放在左右安全区域，中央留给实际挖孔；第二行排在挖孔下方，使用正常上下间距。

- 第一行：左侧专注状态，右侧百分比；中央不放标题、时钟或按钮。
- 第二行：左侧篇名，右侧篇号及小书签入口。头部篇名可截断，正文大标题仍完整显示、保持 small caps。
- 删除“沉浸阅读”等占位行。原顶部时钟移到专注详情中，不再增加第三行。
- 百分比仍可点开查询 / 缓存详情；正在运行的手动请求优先显示其进度。
- 左侧状态可查看上报状态、时间和失败原因；书签入口返回当前书签句。
- 安全范围依据实际挖孔矩形和横屏 / 竖屏重新计算，不用固定百分比猜位置。侧边挖孔、字体放大或空间不足时，缩短状态文案，保留可读和可点范围。
- 生词页沿用两行结构；闲时进度显示今日复习完成情况，运行模型请求时显示请求进度，点开后明确区分两者。

## 4. 导入文章与词库

### 4.1 入口与流程

文章目录提供“导入文章”；生词菜单 / 词库页提供“导入词库”；设置页可放同一个数据管理入口。

流程为：选择文件 → 本地解析 → 预览标题、段落 / 词条、异常与重复项 → 选择导入目标 → 确认 → 一次事务写入 → 显示导入结果。

取消预览不写入正式数据。解析异常逐项列出，用户明确选择跳过错误项后才能提交有效部分。导入本身不调用 LLM；仅在后续主动查询或已经开启静默推理时补分析。

### 4.2 文章规则

- TXT：文件名作为默认标题，空行分段，提交前可改标题。
- Markdown：首个一级标题作为默认标题，显示正文纯文本；代码块、元数据和额外区块在预览中明确处理，不套用预置包的特殊截取规则。
- 一文件默认一篇。ZIP 中多个文件批量导入；批量多文章 JSON 若需要，可沿用 `title + paragraphs` 的明确结构。
- 文章有稳定 ID 和不可变的原文版本，句子和 token 使用该版本的 UTF-16 偏移。标题改名不丢阅读位置、书签、出现记录。
- 正文内容指纹去重，不用文件名去重。相同正文的新文件默认跳过，可修改元信息；相似但不同的文章作为不同版本导入，不静默覆盖。

### 4.3 词库规则

- CSV / TSV 必需列为 `word` 和 `translation`；可选词性、英美音标、频级、词频、排名。支持 UTF-8 BOM，预览中提供字段对应。
- 新建词库或向已有词库合并；同一词元可以属于多个词库，保留每份词库的释义和来源，不直接覆盖已有词典或模型释义。
- 词库导入不自动把整库加入复习。提交后由“随机加入复习”按钮选择少量新词。
- 重复词条的合并规则在预览中可见；有效词总数按唯一词元计，不按 CSV 行数计。
- 上传的音标和释义标为“词库提供”，不伪装成模型生成结果。

文件解析均在后台完成。压缩包按流读取，限制文件数量、解压总量及单项大小，拒绝路径穿越和嵌套压缩炸弹。原文件不必须永久保留，存入规范化正文 / 词条即可；失败或取消清理暂存文件。导入内容只作为数据，不执行脚本、指令或自动访问链接。

## 5. 查词记录与复习库

把三件事拆开：词元是学习对象；出现是文章里的具体词位；复习记录是对一次题目的回答。

- 主动查词成功或命中有效缓存：保存该出现，并把词元加入复习库。静默推理不自动入库、不算主动查询、不增加热度。
- 同一出现重复查询：不重复创建出现，但可更新最近查询时间。不同文章、句子或词位分别保存，不能因词元相同而丢掉本句义。
- “不要了”表示归档并停止推荐，不删除释义、出现或历史。列表可以筛选归档词并恢复。
- 已归档的词再次查询仍能看释义，但不自动解除归档；提供“重新加入复习”动作。
- 已学会不是单次点“记住了”，也不是“不要了”。按稳定度和有效的间隔复习表现判定，并继续保留较长间隔的复习。

旧版本记录只保存文章与词元，不能可靠恢复当时具体点过哪个词位。迁移时保留旧查词并加入复习库；能匹配到的旧缓存原句标注“历史缓存”，不冒充精确的主动查询出现。新版本开始精确记录出现。

## 6. 复习页面

### 6.1 题面与出题

视觉层级为英文目标词 → 四个中文释义色块 → 第五行三个等宽按钮：“记住了 / 忘记了 / 不要了”。题面只展示单词，不显示原句、词性、音标或来源提示；这些信息留到详情页。

把该词所有可用释义汇成候选池：查过的出现中的本句义、所属词库义项、已有模型通用义。相同释义去重后随机抽一个作答案，不让某条义项因为在多处重复而更容易抽到。每个候选保留原始释义、词性（如有）、来源以及原句 / 词库 / 缓存版本。

三个干扰项从其他词的本地释义池抽取：优先同词性、相近长度，排除本词所有已知可成立义项和相同释义。随机选中的答案之外，本词另一个真实义项也不能当成错选项。四个位置随机且在本题生命周期内固定。结构过滤不能保证完全理解语义相近情况；本版用纠错记录收集这种问题，不依据纠错表自动改变出题策略。无法凑齐基本合格的四选项时暂缓该题，不强行编造答案。

出题、判分和排期不逐题调用 LLM。缺少可用释义时，优先使用词库；仍缺失才走模块补缺。提前准备下一题，不让回答后的网络速度决定下一题是否可用。

### 6.2 点击后的状态流

1. 立刻锁定本题，禁止重复计分；正确项用松绿，错误选择用陶土色，其余项减弱。按后续确认取消额外的“正确 / 错误”小字，维持选项高度稳定。
2. 选择正确答案或“记住了”：记一次有效记住；选择错误或“忘记了”：记一次忘记；“不要了”：归档，不把它当成功或失败。
3. 三个按钮的默认语义是本次自评 / 归档，而不是“记住了”直接永久学会。自评未选翻译项时显示正确项，不凭空标一个用户错误选择。
4. 所有按钮点击后均等待 0.5 秒，再用共享字形过渡弹出详情；用户已切页、进入后台或退出则不追着弹窗。
5. 回答与调度结果用一个事务、一个答题 ID 保存。旋转、双击、返回后恢复都不能重复记分。
6. 关闭复习详情进入下一题；没有到期词时明确提示，可选择提前复习或加入新词，不默默改变到期时间。

### 6.3 排期与权重

建议采用本地 FSRS 调度，记录难度、稳定度、预计可回忆率及到期时间；先使用固定版本的默认参数，目标保留率建议 90%，暂不加入个性化参数训练。算法与 UI 分离，用官方参考数据验证移植结果。[FSRS 项目](https://github.com/open-spaced-repetition/free-spaced-repetition-scheduler)，[Anki 官方说明](https://docs.ankiweb.net/deck-options.html#fsrs)。

推荐权重只决定候选顺序，不篡改记忆模型：按后续确认，未复习词严格优先于已复习词；已复习词按到期 / 逾期、近期答错、主动查询频次和词库词频排序。同一轮去重，取消每日最多引入 10 个新词的限制；每日不同复习词数量可配置，默认不限。

初始映射建议为记住 → Good，忘记 → Again，归档 → 不评分。四选题记录为识别型练习，自评保留独立来源，不能宣称已经测得自由回忆能力。初始“已学会”口径建议为稳定度至少 21 天，且最近两次跨日有效复习均记住；它仍保留长期排期。这是产品统计阈值而不是掌握所有义项的客观结论，后续可调整而不改动原始复习日志。

## 7. 单词详情、列表与词库页

### 7.1 共享详情

原词、音标、词库归属、常见义项与派生词复用当前版样式。题目详情首先显示“本题所取释义”，注明来自原句、哪份词库或模型通用义；本题考点不因详情中的其他义项而被覆盖。下方新增“查过的出现”，按最近查询时间列出：来源文章、原文词形、完整原句、目标词标记、该词位的本句释义及查询时间。相同义项不应盖掉其他出现。

出现默认折叠，逐项下弹展开；长列表按需加载。点来源可回到该文章的具体句子和词位，保存复习现场，返回时继续原题 / 列表，不重新洗牌。旧缓存出现和真正主动查询出现使用清楚的来源标签。

复习详情关闭后进入下一题；列表详情关闭后仍在原列表位置。“不要了”后详情仍按要求展示，并提供撤销归档。

### 7.2 列表

按词元字典序，支持搜索和在学 / 已学会 / 已归档筛选。每项以英文词为重心，辅以简短释义、状态和查询次数。

- 点按词：直接用该词字形过渡打开共享详情；关闭后回原列表位置，不出题、不评分、不增加复习热度。
- 长按词：以全页磨砂弹出“记住了 / 忘记了 / 不要了”三项二级菜单，不同时触发点按详情。选记住 / 忘记分别记一次自评并更新排期，选不要归档；完成后返回列表并显示轻量状态反馈。点击磨砂取消不写任何数据。
- 三种动作使用同一套排期 / 归档服务，自评来源与四选题来源分别记录；不制造本不存在的“正确 / 错误选项”。
- 非题目详情和长按动作菜单都没有“题目错误”按钮。列表不自动推进随机复习队列。

### 7.3 词库

从上到下：词库选择 → “随机加入 10 个词” → 已学会占比 → 已查询占比 → 按日热度图。

- 加入对象为该库中未加入复习、未学会、未归档的词，去重后随机；不足 10 个时全部加入并显示实际数量，无合格词时说明原因。
- 占比分母为该词库有效唯一词元数。已查询按主动查询去重词元统计，静默缓存不算；归档不算学会。同一词属于多个词库时共享学习状态。
- 热度图建议显示全局最近 12 周的每日活动，避免文章书签被错误归属给某个词库。点一天打开查询 / 书签 / 复习的分项详情；切换词库不改变全局热度。
- 建议初始热度权重为查询 1、书签推进 1、已提交答案 / 记住或忘记自评 2，并保留各事件原始数量。缓存命中的主动查询也算，后台生成不算；纠错撤评分不抹掉实际做过的练习活动，单纯归档不记复习热度。
- 同一词位同日重复查询合并热度；同一次连续滚动导致的书签推进合并一次；复习按答题 ID 去重。热度是活动强度，不冒充专注时长。
- 保存 UTC 时间及事件发生时的本地日期，避免日后改变设备时区使旧热度图迁移。

## 8. 重新生成与题目纠错

### 8.1 文章详情的重新生成

单词 / 句子分析详情右上角放小型 `↻` 图标，触摸范围不小于现有可点击控件。点开二级菜单后选择项目并确认请求：

- 单词：本句释义、常见义项、派生词、音标或全部。
- 句子：整句翻译、从句划分、词汇讲解或全部。

这是用户明确授权的强制更新，区别于普通查缓存 / 补缺。原结果保留可读，按所选模块显示进度；新结果通过格式、范围与词位校验后事务替换所选模块，失败保留原结果。通用义 / 音标更新会被所有出现共享，本句义只更新该出现对应的语境。

同模块已在请求时附着当前任务，不再重复发请求。离开详情不取消已发出的调用，仍在右上角显示进度。模块采用更新序号，旧请求较晚返回不能覆盖新的有效结果；新结果不足或校验失败不能把旧模块擦空。

重新生成本身不重置复习记忆状态；对应释义更新会让关联题目快照失效并重建选项。

### 8.2 题目详情的题目错误

只有从题目打开的单词详情显示纠错图标。二级菜单建议含：干扰义项与正确义相近、多个答案成立、正确释义有误、词形 / 上下文不匹配、其他。

本版只做记录与撤销评分：

- 独立 `question_issue` 表保存题目 ID、词元、四个选项快照、随机选中的正确释义及其来源、用户选择 / 自评、评分 ID、错误类型、时间和题库版本。释义只有来源引用不够，必须同时保存快照，防止以后缓存更新后丢掉当时题目。
- 在主学习数据中将该次评分标为已撤销，恢复相应记忆状态 / 到期时间；保留其他有效评分。重复提交同一题不能重复回滚。如果存在更新的评分，应按有效评分日志重算，不能把旧快照直接覆盖回去。
- 不修改词典、词义缓存、出现、查词记录或归档状态，也不删除“确实完成过一次练习”的活动热度。未产生评分的“不要了”题只记录问题，不撤销归档。
- 不自动加入干扰项黑名单、不暂停释义、不自动重出题、不发纠错 LLM 请求、不上传报告。先积累数据，后续版本再设计分类处理逻辑。

## 9. 数据层与调用边界

现有 `analysis` 表没有独立 provider 列；提供商端点和模型参与了句子缓存哈希。需要改变缓存身份并迁移，不是删一个字段即可。

建议按职责增加下列实体：

当前文章数组和合并词典由只读 assets 一次加载。需要改为统一内容仓库：保留内置文章 / 词库身份，合并本地导入数据，向页面提供可观察的列表和词库成员关系；导入成功后即时刷新，而不要求重启应用。新词库不能改变已有学习词元 ID，词形归并差异用别名处理。

| 实体 | 关键内容 |
|---|---|
| Article / ArticleVersion | 稳定文章 ID、标题、正文版本、内容指纹、来源、阅读位置 |
| Word | 稳定词元 ID、规范词元；出现保留实际词形 |
| WordBank / Membership | 词库及成员关系、各库独立释义 / 音标 / 排名 |
| Occurrence | 文章版本、段 / 句、UTF-16 词位、实际词形、语境键 |
| LookupHistory | 主动查询的出现、时间、成功状态；旧的词元级记录保留 |
| AnalysisModule | 通用义 / 派生词 / 音标 / 本句义 / 句子模块及校验后的内容 |
| StudyWord | 在学 / 已学会 / 归档、记忆状态、到期时间、进入来源 |
| QuestionSnapshot / ReviewAttempt | 固定题面选项、绑定义项版本、选择 / 自评、评分、有效性 |
| QuestionIssue | 独立纠错表，保留题目 / 释义 / 选项快照、错误类型、评分撤销状态 |
| ActivityEvent | 查询 / 书签 / 复习事件、去重键、本地日期、有效性 |
| ImportBatch / GuideState | 暂存 / 提交 / 取消状态，引导版本与进度 |

新句子缓存以原文内容及确实需要的语境、模块、结构版本为键，不含提供商、模型或协议。语境使用内容指纹而不是随机导入 ID；词位索引始终绑定原文版本。不把提示词的小修改等同于所有兼容缓存失效。

模块边界一致：词元通用义和派生词共享，音标按实际词形共享，本句义按原句与词位区分；句子的译文、从句和词汇讲解也可独立补缺 / 重生成。模型配置只决定缺失或强制更新时向谁请求，不决定已有学习数据属于谁。

调用流程为：定位内容与模块 → 读共享缓存 → 恢复可识别旧缓存 → 判断缺失 → 复用在途任务或发一个请求 → 校验 → 模块事务合并 → 通知页面 / 题库刷新。主动查词成功另写出现和学习事件；后台补齐不伪造主动查询。

旧句子哈希不可逆。迁移使用已知文章原句、曾使用的端点 / 模型组合找到旧键，校验后复制到共享键；冲突优先采用完整、可验证、较新结果，不把两份相互矛盾的从句区间胡乱拼接。迁移不调用 LLM、不清空旧数据库；未知来源的旧哈希保留而不丢弃。

导入、迁移、答题和更新均有可恢复的事务边界。迁移前做一致性备份，失败不破坏原有阅读 / 查询。开发构建和大体积暂存继续使用 E 盘。

## 10. 浮层与引导

所有覆盖层只使用全页磨砂与文字 / 必要色块，不再给详情加灰底或另一个卡片。浮层按栈管理：只顶层响应；点磨砂或返回只退一层，正文磨砂不因层数无限叠加。

原词 / 原句复用字形位置过渡，目标位置始终横向居中；其余元素沿用 70% 大小、透明、靠上起始的逐项下弹。复习题面、列表词条和详情都提供实际字形锚点，不能从虚构屏幕位置飞入。原字形只有一份，动画结束才交给最终文字，避免重影；浅 / 深主题均保留颜色。

首次安装显示四步极简引导：点击查词 → 长按看句子 → 书签随阅读推进 → 左右滑动。用本地简单 SVG / 原生矢量图与小型磨砂说明，不使用照片或额外不透明背景。

引导演示不发 LLM、不写查词、不移动真实书签、不产生热度。可跳过，在设置重播；中途退出下次继续，明确跳过则记为完成。旧用户升级只显示新生词入口 / 手势的简短提示，不强迫重新看完整引导。

学习中的复习和详情可以延续现有专注上报；进入设置、菜单或导入流程停止。仍只使用用户已经配置的科目 / 事项，不新增硬编码上报链接或密钥。

## 11. 实施与验收顺序

1. 先落共享句子缓存、出现记录和内容仓库，验证旧缓存 / 书签 / 查词无损迁移。
2. 做导入预览与提交，验证重复、坏编码、异常行、批量包、取消、重启和路径安全。
3. 做双主页面与双菜单、两行沉浸顶栏，在挖孔、大字体、横竖屏和深浅主题截图核对。
4. 做本地题库与调度、列表 / 词库 / 热度图，验证重复答题、离线、归档 / 恢复和到期顺序。
5. 做共享详情、出现跳转、按模块重生成及纠错回滚，逐帧验证阅读 / 题目 / 列表的动效。
6. 做无副作用引导，完成设备回归后再决定版本号和发布。

重点验收：切换任意服务仍命中句子缓存；新文章可读且词位正确；相同词不同出现保留不同本句义；本词其他真实义项不会被拿来作干扰项；纠错记录完整且只撤销目标评分，不误覆盖其他历史；“不要了”不抹除数据；异常请求不清空旧结果；导入 / 动画 / 500ms 延时被打断时不重复落库、不突然跨页弹窗。
