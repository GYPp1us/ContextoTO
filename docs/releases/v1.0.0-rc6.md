# v1.0.0-rc6

versionCode 14，沿用已有发布签名，可覆盖安装。

## 解析与数据

- 真正独立的最小输入 / 输出模块，并行补缺、逐模块验证与落库、跨提供商在途去重；失败重试不重查已成功项，关闭详情后请求继续。
- 仅 OFF / MAX：原型、IPA、通用义、本句义关闭思考；派生词、整句翻译和从句结构 MAX，不暗中降档。CC Chat / Responses 参数分别适配。
- 变形词展示正确原型，出现相关词元缓存避免多义词串库。优先恢复旧完整音标，再补字典 / 网络缺失口音。
- 通用 ECDICT 10,000 独立词元及词形索引。词库搜索预览、自定义库重命名 / 合并 / CSV 导出 / 确认删除；删除来源保留已入库词释义快照和学习记录，不做单个词条编辑。
- N01 / N02 预制 120 句、2,582 词位完整解析；离线命中，不自动进入复习，不计查询和热度。
- 文章与解析 ZIP 导入 / 导出：版本、校验哈希、体积 / 路径 / 范围验证、事务补缺，保留有效本机解析。明确排除全部私人学习记录和配置。

## 交互修正

- 状态栏覆盖区不触发下层文本交互；书签画布和正文统一坐标，修正一个顶栏高度的上移。
- 目录固定磨砂顶 / 底栏，入口间距压缩；设置入口整行可点。空白遮罩无 ripple，箭头按压仅改文字和线条颜色。
- 第四面板项目直接跟随拖动进度，不在落位后重复入场；启动与吸附阈值下调约 20%。COLLECTION / WORDS 与 ARTICLES 标题同级。
- 设置具体项目中文无衬线，大类英文衬线。收起展开块时下方正常补位，只保护必要的页面尾部高度，向上逐渐回收。
- 长按自评菜单在按下位置附近限位弹出；ANSWER 自评后关闭整张详情并进入下一题，不只隐藏原词。二级菜单不重复加深全页滤色。
- 独立模块返回时，已出现的说明不因别的模块到达反复入场；部分句子结果仍能显示补缺进度 / 错误。
- 引导与练习浮层全程屏蔽系统返回；增加 AI、额度、离线缓存和失败降级说明。

## 验证与限制

51 项单元测试、27 项 Android runner 测试通过；覆盖缓存迁移、最小输入 / 并行、失败补缺、再生成重试、单口音补缺、ZIP 私密数据排除 / 校验、删除词库保留学习、rc5 数据升级以及两篇预制全覆盖。CI 增加离线预置校验。

CC Responses 实测独立 IPA `none` 为 0 推理 token，翻译 MAX 正常完成；官方 DeepSeek 仅在最终做一次 IPA OFF 和一次翻译 MAX 小请求，均正常完成。官方 OFF 没有返回可观察的推理文本、未报告推理 token 用量，不把缺失用量写成精确 0。

深浅主题、目录整行点击、书签位置、实际引导 / 系统返回、页高回收、附近菜单及答题详情收起使用专用模拟器检查。大型下载、生成、构建与截图均放 E 盘，未操作其他项目模拟器。

模型解析不是人工审校保证。进度为分模块估算；系统强制终止应用进程时不能保证后台请求继续。非兼容模型会明确报错，不擅自改变 MAX / OFF 策略。

数据来源与复现见 [预置数据说明](../PRESET_DATA.md)，上一轮实验见 [实验记录](../WORD_REASONING_EXPERIMENT.md)。API 兼容字段依据官方 OpenAI 文档核对；CC 参数另用真实最小请求验证，不把网关扩展当作 OpenAI 通用规则。
