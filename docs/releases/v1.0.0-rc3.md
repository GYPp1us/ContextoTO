## ContextoTO 1.0.0-rc3

- 模型目录：Chat Completions 与 Responses 共用 `/v1/models`，支持刷新、搜索、选择与手动填写，分别保存各提供商的模型与协议。
- 设置重排：整行可点击的开关背景、衬线分区标题、正文比例/模型/专注折叠组及逐项下弹动画；保存始终固定底部且不遮挡设置内容。
- 句子书签：沿每行文本形成圆角透明轮廓，首尾缺角平滑变形，滚动或查询后向前跟随；旧书签无损迁移。
- 已查询词：选项开启后改为加粗，保留正文及从句颜色，默认关闭。
- 缓存复用：单词的本句义、常见义项、派生词和音标不再依赖服务/模型/协议；旧记录按需合并，切换提供商不破坏缓存。

兼容 Android 12 及以上，沿用现有发布签名，可覆盖安装。API Key 和专注上报令牌不随 APK 分发。
