## ContextoTO 1.0.0-rc4

- 四页面：文章目录｜文章｜生词｜生词菜单。文章与生词平级切换，左右菜单宽 80%、主页面错移 60%；所有覆盖层保持全页磨砂。
- 生词系统：复习、字典序列表、词库统计和 12 周全局活动热度图。主动查词自动加入复习，词库可随机加入 10 个新词；归档可恢复，不删除查询或缓存。
- 本地四选题：从本句义、词库义与已缓存通用义中随机选答案，题面只展示单词；排除该词其他已知正确义项。即时反馈后 0.5 秒弹出共享词详情，显示答案来源和查询出现。列表点按查看，长按记住 / 忘记 / 归档。
- 本地调度：版本化指数遗忘曲线，记住增长稳定度，忘记缩短间隔；到期优先，并按难度、查询出现数与词频排序，每日最多 10 个新词。本版不标称 FSRS、不做个性化训练；“已学会”统计为稳定度至少 21 天及两次跨日记住。
- 独立纠错表：仅记录题目快照和错误类型，幂等撤销对应评分并重放后续有效记录；不自动改变出题策略、释义、缓存、归档或活动热度，不上传报告。
- 本地导入：TXT / Markdown 文章、UTF-8 CSV / TSV 词库和 ZIP 批量包。先预览再事务提交，内容去重；保留多库释义来源及词库音标。词库必需列 `word,translation`（支持 `单词,释义`），可选 `pos,ipa_uk,ipa_us,rank,frequency`。不支持 PDF / Word / Excel / tar.gz。
- 缓存迁移：句子不再以提供商、模型或协议区分，按需恢复旧哈希；词元模块跨提供商共享。文章详情可分别重新生成词义 / 音标 / 派生词及句子译文 / 从句 / 词汇，有效旧数据不因失败丢失。离开浮层不终止已发请求，进度继续显示。
- 精确出现：新查询保存文章、段、词位、原句和本句义。旧记录只显示可证实的历史查询，不伪造当时的具体词位。数据库升级采用事务并保留升级前恢复副本。
- 沉浸顶栏：两侧“专注 / 百分比”，下一行“标题 / 编号 / 书签”；不再保留整条挖孔空白。专注详情显示时间与上报状态。生词页百分比显示后台查询或今日复习进度。
- 极简矢量引导：首次启动说明点按、长按、书签及四页面；可跳过、续看、重看，老用户只提示新滑动布局。引导不调用模型或写学习活动。

Android 12 及以上；沿用现有发布签名，可覆盖安装。密钥与专注上报链接仍只保存在设备，不随 APK / 仓库分发。

验证：40 项本地单元测试；14 项 Android runner 用例（12 项实际缓存 / 数据集成测试，另 2 项为未启用的视觉夹具入口）。模拟器截图检查引导、四页面、答题 / 纠错、列表动作、词库热度与系统选择器导入。DeepSeek 官方目录与流式音标补缺验收通过，一次生成共 247 token，未保存密钥。
