## ContextoTO 1.0.0-rc5

- 四面板滑动跟手、限位、按距离与速度吸附，归位动画可被再次拖动打断；按住后松手不沿用陈旧甩动速度。目录 / 生词菜单全屏可横向拖动，点击外露主页面收起时不再提前撤掉磨砂。
- 切换文章或生词模式使用 10% 缩放的卡牌交换，连同归位共 400ms。设置位于文章左侧、目录下层；进入时阅读继续移出，保存 / 返回直接平移回文章，不再闪现目录。
- 展开项收起后暂留原高度，滚动到页面末端向上逐步回收，避免内容突然跳动；未回收的超出区域不接受向下滚动。
- 磨砂统一增强，叠加 20% 同背景色滤光；沉浸顶栏与固定保存栏重绘模糊正文，内容可延伸到其下。挖孔预留默认缩至旧值 70%，设置可调 30%–150%。目录中当前文章使用浅背景突出，取消底部小说明。
- 跳转入口统一为文字下划线与上侧半箭头；系统操作使用无衬线，内容使用衬线，UI 标题统一加粗大写英文衬线。原文过渡保持原字形与字重。
- 引导示例居中并可真正点按 / 长按，矢量图与箭头指向示例；点击空白不退出引导。练习不调用模型、不写学习记录。
- 复习新词严格优先于已复习词，同轮去重，取消每日 10 个新词限制。新增每日不同复习词上限（默认 0，不限，可设 0–2000）；词库随机加入数量可设 1–500，默认 10，按钮加入延迟反馈与防重复点击。
- 题库释义索引复用，后台只读准备下一题；等待时展示读取、索引、筛选与组装阶段，激活时事务保存并再次校验释义。题目使用下弹入场；答题反馈不增添改变按钮高度的标签，复习结束增加矢量庆祝图。
- 答题详情点空白关闭，题面原词不再飞回消失的位置，与解释一同收起，下一题同步入场；长按可调整记住 / 忘记 / 归档，修改原评分而非重复记分或热度。撤销的错误题评分不会被重新自评恢复。

Android 12 及以上；版本代码 13，沿用现有发布签名。可覆盖安装 rc4，保留文章、词库、查询、书签、学习记录和跨提供商模型缓存，本版不改变数据库结构。API 密钥及专注上报链接仍仅保存在设备，不随 APK / 仓库分发。

验证：44 项单元测试；19 项 Android runner 用例（17 项实际数据 / 缓存集成测试，另 2 项为未启用的视觉夹具入口）。模拟器截图检查深浅主题、跟手中间态、设置进退、展开余量回收、引导演示、答题详情与快速重复入库。本轮不发送付费模型请求；本地缓存、编译产物与截图均放在 E 盘。

交互和数据流细节见 [验收记录](../INTERACTION_ITERATION.md)。
