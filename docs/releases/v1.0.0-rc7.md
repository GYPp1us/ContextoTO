# v1.0.0-rc7

versionCode 15，沿用 RC 系列的签名和数据格式，可覆盖安装。

在 [rc6](v1.0.0-rc6.md) 基础上：

- 引导返回键可收起单词 / 句子演示；句中点词真正展开单词详情，并保留原词过渡。嵌套单词返回到句子，再返回到引导，引导本身不会因系统返回退出。演示仍使用本地内容，不请求模型或写学习记录。
- AI 来源、可能出错和不可用时查看原文 / 词典 / 缓存的说明移到引导外层。弹出页不再放提示词、模块或思考强度等实现细节。
- 目录上下玻璃去掉不透明底板和二次滤色，无加深阴影；原始清晰列表在两栏下裁去，仅重绘其模糊副本，不制造透字重影。
- 所有大写衬线加粗 UI 标题统一 small caps：各词首字母全高，余下英文字母 78% 高度；数字、符号和主题颜色保留。正文标题与原词过渡不受影响。
- 沉浸式状态栏默认开启。已有用户明确关闭的选择不被覆盖；其余阅读、模型、学习和缓存设置保留。
- 字典与字体许可原文随 APK 预置，并保留仓库来源说明。

保留 RC6 的独立模块查询、OFF / MAX 策略、10,000 通用词元、前两篇 120 句 / 2,582 词位预制、文章与解析 ZIP 迁移，以及全部本地学习功能。不改变预置解析哈希、数据库版本或缓存地址，不需要重新生成已有数据。

验证：54 项单元测试、28 项 Android runner 测试通过。small caps 尺寸 / 颜色、引导逐层返回和默认沉浸 / 显式关闭兼容均有回归测试；深浅主题、引导嵌套点词与返回、目录玻璃使用专用模拟器截图验收。本轮不发送付费模型请求。临时构建、下载、模拟器与截图继续放 E 盘。
