# 发布前交互细化

本轮基于 `v1.0.0-rc4`，发布为 `v1.0.0-rc5`。没有清空、重建或破坏已有文章、词库、查询、书签和模型缓存。

## 面板与动效

- 空间顺序仍为目录、阅读、生词、生词菜单。横向位移跟随手指，限位到相邻页面，松手按距离和速度吸附。归位动画可被下一次拖动打断；目录 / 菜单全屏接受横向手势，其自身区域才接受纵向滚动。
- 菜单外露的主页面点击直接收起，不在第一帧提前撤除磨砂。选择不同文章或生词模式时，旧卡片退出并缩小 10%，新卡片滑入并放大，最后连续归位；三个阶段为 120 + 120 + 160 ms。选择当前内容只归位。
- 设置完整布局在阅读左边、目录下面。由目录进入时，目录收起而阅读继续移出；返回 / 保存直接平移到阅读，不重新显示目录，也不吸附到目录坐标。设置退出内容保留到整页离场，避免半途消失。
- 单词详情退出时：阅读 / 列表词仍回原位置；答题词不回已经不存在的题面，与解释一同淡出 / 缩小。同时下一题以 70% 大小、向下淡入。
- 展开项收起保留测得的高度；到内容末端时由上滑逐步回收。回收期间向下手势不进入超出区域；嵌套折叠只计外层可见余量，避免重复扣除。

## 阅读与排版

- 当前文章在目录中有浅背景突出，取消目录底部三项小说明；仍保留每篇的查询数量与上次阅读标识。
- 系统说明、操作、输入使用无衬线；正文、释义和英文词使用衬线。UI 标题统一加粗大写英文衬线；过渡中的原词、原句保持正常字重 / 原有字形样式。
- 跳转入口统一为文字下划线，右端只有向上半箭羽；加粗文字对应稍粗线条。
- 沉浸顶栏两行布局保持不变，挖孔留高默认为旧值 70%，范围 30%–150%。顶栏覆盖模糊后的正文，不再用大块空白避让；正文可延伸至其下。
- 统一磨砂半径 34px（原为约 23–26px），叠加 20% 不透明度同纸面色滤光。保存栏和顶栏重绘原内容的模糊副本，遮住未模糊的原始文字，避免重影。没有给详情增加灰色背景卡片。

## 复习数据流

1. 本地读取学习队列，新词始终先于已复习词；同一轮用词元去重。
2. 复用词库释义索引，按词性采样干扰项；排除本词所有真实释义和重复选项。
3. 后台异步组装下一题，只读准备不提前写当前题；激活时以事务保存固定选项。首次需要等待时展示读取、索引、筛选和组装阶段。
4. 答题即时显示色块反馈，不增添会改变按钮高度的正确 / 错误标签；500ms 后展开共享详情。
5. 空白关闭进入下一题，长按详情可改记住 / 忘记 / 归档。更改已存在的评分使用原答题 ID，保留原评分时间，重放后续有效记录，不重复计热度；此前只归档而没有评分的题改为记住 / 忘记，才记录首次评分。纠错撤销的评分不能因自评恢复。

取消每日 10 个新词限制。新增每日不同复习词上限：默认 0 不限，可设 0–2000；达到数量明确提示，跨日重新计算。每次词库随机加入数量默认 10，可设 1–500；按钮先反馈动画、延迟 180ms 提交，随后保留 650ms 锁定，显示实际加入数量。归档词不被随机重新加入。

## 引导

前两步的英文示例居中，可真正点击 / 长按；原生矢量图与箭头指向示例。空白不退出整个引导，仅关闭演示详情。练习使用固定本地释义，不调用模型、不记录查询、不移动书签、不计热度。保留跳过和下一步。

## 验证

- 单元测试覆盖 44 项：包括面板锚点 / 限位、按住后松手不沿用旧速度、释义索引去重以及现有字形、书签、模型协议和下载行为。
- Android runner 19 项（17 项实际数据 / 缓存集成测试，另 2 项为需显式启用的视觉夹具入口，本轮未启用）；新增覆盖超过 10 个新词、忘记词不能压过新词、准备只读、每日数量、原评分修改、归档改回及更新评分保留；预生成题在释义变化后再次校验，不能激活已失效答案或已成为真义的干扰项。
- 模拟器截图核对深浅主题、目录高亮 / 外露区域收起、手指未松开的中间态、设置进入与固定保存栏、展开 / 收起的位置保持及空白回收、真实引导练习、答题详情 / 下一题、生词菜单 / 词库及快速重复入库。入库数改为 2 后连续点两次，生词数量从 3 增至 5。
- 本地编译、缓存与模拟器截图均使用 E 盘；专用模拟器 1080×2376、440dpi，不操作其他项目的模拟器。
- 本轮 UI / 队列测试不发送付费模型请求。
